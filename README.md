# usage-buddy

A Claude Code mod that puts the Clawd mascot above the prompt, animated by what Claude is doing, next to bars for your 5-hour and weekly plan usage.

## Install

In a Claude Code terminal session, type:

```
/plugin install usage-buddy --marketplace mteusbarbosa/usage-buddy
```

Answer `y` to add the marketplace, then press Enter to pick the user scope. The band shows up right away, and in every session after, including the Claude desktop app's Code tab.

## Use

- `/usage-band` shows or hides the band.

## Update

```
claude plugin update usage-buddy
```
